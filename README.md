One line roasting the smart fridge: it tattles to your fitness app about the 2 a.m. cheesecake, locks the freezer, and asks you to rate your willpower on a scale of one to salad.

## Run it

```sh
python3 main.py
```

The program writes the roast (one line, 156 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
